##  Sobre

Este projeto tem como objetivo gerenciar entradas e saídas de produtos em estoque, permitindo ao usuário:

- Cadastrar novos produtos.  
- Registrar movimentações de entrada e saída.  
- Consultar histórico e filtrar por data e produto.  

---

##  Funcionalidades

- **Cadastro de produtos**: nome, categoria, quantidade inicial.  
- **Movimentações**: registrar entradas e saídas com data e observações.  
- **Listagem**: visualizar e filtrar movimentações.  
- **Interface responsiva**: funciona em desktop e mobile.  

---

##  Tecnologias Utilizadas

- **Frontend**: React, Tailwind CSS, Vite  
- **Backend**: Node.js, Express (ou PHP/Laravel, ajustar conforme o projeto)  
- **Banco de Dados**: MySQL (ou outro, ajustar conforme o projeto)  
- **Controle de Versão**: Git e GitHub
